# الموقع الشخصي لعلي عباس عبود

موقع شخصي يعرض التطبيقات والسيرة الذاتية والروابط البحثية. يعمل الموقع مباشرةً دون تثبيت أي برامج أو مكتبات.

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه ملفات الموقع، بما فيها `index.html` و`AliCV 2026 Ar.pdf` في المجلد الرئيسي نفسه.
2. من إعدادات المستودع، افتح **Pages** واختر **Deploy from a branch**.
3. اختر فرع `main` والمجلد `/ (root)`، ثم احفظ الإعدادات. سيظهر رابط الموقع في صفحة إعدادات Pages بعد النشر.

يمكن تحديث السيرة باستبدال ملف PDF مع الإبقاء على الاسم نفسه، أو تعديل رابطها في `index.html` إذا تغير اسم الملف.
